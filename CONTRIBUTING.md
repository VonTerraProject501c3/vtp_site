# Contributing

**Do not file issues here. File them in [`vtp_command`](https://github.com/VonTerraProject501c3/vtp_command/issues).**

This repository holds the public website at vonterraproject.org. It is one of four repositories that make up The Von Terra Project,
and they are worked as one system rather than four separate projects.

Everything goes through `vtp_command` — the control plane. That is where proposals are tracked,
triaged, and turned into work. Filing here instead means your issue lands outside the list the
maintainers actually work from.

**[Read the full contributing guide →](https://github.com/VonTerraProject501c3/vtp_command/blob/main/CONTRIBUTING.md)**

## The short version

- **Describe the change you want. Don't build it.** Write it in plain English, the way you would
  explain it to a colleague. VTP's developers handle the technical side.
- **You do not need to know git, HTML, or which repo owns what.** Requiring code would silence
  exactly the people whose judgment matters most here.
- **One door: `vtp_command`.** Not sure it is worth raising? Raise it. Triage is cheap.
- **No personal information and no Google Drive content in issues.** Both are permanent, and
  this organization has a public repository.
