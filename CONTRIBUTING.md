# Contributing

**Part of VTP? File issues in [`vtp_intake`](https://github.com/VonTerraProject501c3/vtp_intake/issues/new/choose). Not part of VTP? Use the [issue forms here](../../issues/new/choose) or the [contact page](https://vonterraproject.org/contact.html).**

This repository holds the public website at vonterraproject.org. It is one of five repositories that make up The Von Terra Project,
and they are worked as one system rather than five separate projects.

If you are a VTP director, staff member, volunteer or invited contributor, everything you want
changed goes in through `vtp_intake`, the one door, even when it is about the website. A maintainer
reads it there, routes it to the repository that owns it, and tracks it in `vtp_command`. Filing
here instead means your issue lands outside the list the maintainers actually work from and skips
the check that reads every intake issue for personal information.

If you are not part of VTP, you cannot see `vtp_intake`. Report a website problem with the issue
forms in this repository, or write to the organization through the contact page. Both are read.

**[Read the full contributing guide](https://github.com/VonTerraProject501c3/vtp_command/blob/main/CONTRIBUTING.md)**

## The short version

- **Describe the change you want. Don't build it.** Write it in plain English, the way you would
  explain it to a colleague. VTP's developers handle the technical side.
- **You do not need to know git, HTML, or which repo owns what.** Requiring code would silence
  exactly the people whose judgment matters most here.
- **One door for people inside VTP: `vtp_intake`.** Everyone else: the forms here or the contact page. Not sure it is worth raising? Raise it. Triage is cheap.
- **No personal information and no Google Drive content in issues.** Both are permanent, and
  this organization has a public repository.
